# Bank Backend

Node.js backend with embedded local PostgreSQL for the Bank admin and file management app.

## Setup

1. Copy `.env.example` to `.env`. PostgreSQL is embedded by default, so no separate DB install is needed.
2. Set `PG_EMBEDDED=false` only if you want to point at an external PostgreSQL server. For local dev, keep embedded mode on.
3. No manual database creation is needed in embedded mode. The app will create `PG_DATABASE` automatically.
4. Install dependencies:
   ```bash
   npm install
   ```
4. Start the API:
   ```bash
   npm run start
   ```

## Notes

- User avatars can use a gender-based default image until a custom profile image is uploaded.
- File uploads are stored locally under `backend/uploads`.
- File and avatar view URLs are short-lived signed URLs generated by the backend.
- Settings are stored in PostgreSQL and include SMTP and password-reset email template content.
- `npm run seed:db` seeds default RBAC roles, demo employee accounts, and the banking masters/demo transaction data.
- Seeded accounts are idempotent and re-run with the same credentials on each seed.
- API requests are rate limited, auth endpoints are stricter, and CORS is allowlisted.
